MD5与SHA签名逆向分析

发表于2026-10-17|更新于2026-10-18|反爬技巧
|浏览量:

适用场景

接口有sign参数，是32位（MD5）或40位（SHA1）或64位（SHA256）的十六进制字符串。需要分析签名规则，找到盐值，用Python复现。

实现原理

MD5和SHA都是哈希算法，把任意长度的输入转成固定长度的输出。网站常用它们做接口签名：把请求参数按一定规则拼接，加上密钥（盐值），然后哈希得到sign。服务器用同样的方式计算，对比是否一致。

具体步骤

第一步：识别哈希类型

根据签名长度判断：

  • 32位十六进制 → MD5（最常见）
  • 40位十六进制 → SHA1
  • 64位十六进制 → SHA256
  • 128位十六进制 → SHA512

第二步：定位签名代码

  1. F12 → Sources → 搜索md5、sha1、sha256、sign
  2. 或者XHR断点，在请求发出时断住
  3. 查看调用栈，找到生成sign的函数
  4. 在函数入口打断点，查看输入参数

第三步：分析签名规则

常见的签名模式：

模式1：参数排序+拼接+盐值

模式2：时间戳+盐值

模式3：HMAC

模式4：多层哈希

第四步：查找盐值（密钥）

盐值可能的位置：

  1. 硬编码在JS里（搜索secret、key、salt、appkey）
  2. 从接口动态获取
  3. 由用户ID和固定字符串组合
  4. 放在Cookie或LocalStorage里
  5. 经过混淆或变换

技巧：

  • 用已知的参数和sign，反推可能的盐值
  • 对比多次请求，找出不变的部分
  • 在加密函数处断点，查看拼接后的完整字符串

注意事项

  1. 大小写 — 有些网站要大写MD5，有些要小写，注意区分
  2. 参数顺序 — 排序方式很重要，有些按ASCII排序，有些按参数名排序
  3. 拼接格式 — 注意是key=value&还是keyvalue，有没有分隔符
  4. 盐值位置 — 盐值可能在开头、中间或结尾，要仔细看JS
  5. 编码问题 — 中文参数要注意URL编码，和JS里的编码方式一致
