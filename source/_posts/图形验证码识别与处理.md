## 适用场景

网站登录或请求时需要输入验证码，包括数字字母验证码、滑块验证码、点选验证码等。需要自动识别或绕过验证码。

## 实现原理

验证码是网站区分人和机器的常用手段。处理方式有三种：1）用OCR技术自动识别简单验证码；2）接入第三方打码平台人工识别；3）用机器学习/深度学习训练模型识别。复杂的滑块、点选验证码需要更高级的技术。

## 具体步骤

### 第一步：验证码类型识别

常见验证码类型：
1. **数字字母验证码** — 最简单，4-6位字符，OCR可识别
2. **算术验证码** — 如"3+5=?"，需要识别后计算
3. **滑块验证码** — 拖动滑块到缺口位置
4. **点选验证码** — 按顺序点击文字或图标
5. **行为验证码** — 检测鼠标轨迹，如极验、reCAPTCHA

### 第二步：简单OCR识别（pytesseract）

```bash
pip install pytesseract pillow
# 需要安装Tesseract-OCR程序：https://github.com/UB-Mannheim/tesseract/wiki
```

```python
import requests
from PIL import Image
import pytesseract

def recognize_captcha(image_url):
    """识别简单数字字母验证码"""
    # 下载验证码图片
    response = requests.get(image_url)
    with open("captcha.jpg", "wb") as f:
        f.write(response.content)
    
    # 打开图片
    image = Image.open("captcha.jpg")
    
    # 灰度化
    image = image.convert("L")
    
    # 二值化
    threshold = 127
    image = image.point(lambda x: 0 if x < threshold else 255)
    
    # OCR识别
    text = pytesseract.image_to_string(image, config="--psm 7")
    return text.strip()
```

### 第三步：ddddocr（推荐）

ddddocr是专门针对验证码的OCR库，识别率比tesseract高：

```bash
pip install ddddocr
```

```python
import ddddocr

ocr = ddddocr.DdddOcr()

def recognize_captcha(image_bytes):
    """用ddddocr识别验证码"""
    result = ocr.classification(image_bytes)
    return result

# 使用
response = requests.get("https://example.com/captcha")
code = recognize_captcha(response.content)
print(f"识别结果: {code}")
```

### 第四步：打码平台接入

复杂验证码用打码平台人工识别：

推荐平台：
- 超级鹰、打码兔、图鉴（国内）
- 2Captcha、Anti-Captcha（海外）

```python
import requests

class ChaoJiYing:
    """超级鹰打码平台"""
    def __init__(self, username, password, app_id):
        self.username = username
        self.password = password
        self.app_id = app_id
        self.base_url = "https://upload.chaojiying.net/Upload/Processing.php"
    
    def recognize(self, image_bytes, cod_type=1902):
        """
        cod_type: 验证码类型
        1902: 常见4-6位字符
        6001: 滑块验证码
        9001: 点选验证码
        """
        data = {
            "user": self.username,
            "pass": self.password,
            "softid": self.app_id,
            "codetype": cod_type
        }
        files = {"userfile": ("captcha.jpg", image_bytes)}
        response = requests.post(self.base_url, data=data, files=files)
        result = response.json()
        if result["err_no"] == 0:
            return result["pic_str"]
        else:
            print(f"识别失败: {result['err_str']}")
            return None

# 使用
cjy = ChaoJiYing("username", "password", "app_id")
response = requests.get("https://example.com/captcha")
code = cjy.recognize(response.content)
print(f"打码结果: {code}")
```

### 第五步：验证码处理策略

```python
class CaptchaHandler:
    def __init__(self):
        self.ocr = ddddocr.DdddOcr()
        self.cjy = ChaoJiYing("username", "password", "app_id")
    
    def handle_simple_captcha(self, image_bytes):
        """简单验证码用OCR，失败用打码平台"""
        # 先用免费OCR
        result = self.ocr.classification(image_bytes)
        if len(result) >= 4:  # 识别结果合理
            return result
        # OCR失败，用打码平台
        return self.cjy.recognize(image_bytes)
    
    def handle_slider_captcha(self, image_bytes):
        """滑块验证码用打码平台"""
        return self.cjy.recognize(image_bytes, cod_type=6001)
    
    def handle_click_captcha(self, image_bytes):
        """点选验证码用打码平台"""
        return self.cjy.recognize(image_bytes, cod_type=9001)
```

### 第六步：避免触发验证码

最好的处理是不触发验证码：
1. 控制请求频率，加随机延时
2. 使用代理池轮换IP
3. 维护登录态，已登录用户验证码少
4. 模拟真实浏览器行为（Selenium/Playwright）
5. 使用Cookie池，多账号轮询

## 完整代码

```python
import requests
import ddddocr
import time
import random

class CaptchaSpider:
    def __init__(self):
        self.session = requests.Session()
        self.ocr = ddddocr.DdddOcr()
        self.headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"}
    
    def get_captcha(self):
        """获取验证码"""
        response = self.session.get("https://example.com/captcha", headers=self.headers)
        return response.content
    
    def login(self, username, password):
        """带验证码登录"""
        max_retries = 5
        for retry in range(max_retries):
            # 获取验证码
            captcha_img = self.get_captcha()
            captcha_code = self.ocr.classification(captcha_img)
            
            if len(captcha_code) < 4:
                print(f"验证码识别失败，重试 {retry+1}/{max_retries}")
                time.sleep(1)
                continue
            
            # 提交登录
            data = {
                "username": username,
                "password": password,
                "captcha": captcha_code
            }
            response = self.session.post(
                "https://example.com/login",
                data=data,
                headers=self.headers
            )
            
            if "登录成功" in response.text:
                print("登录成功")
                return True
            elif "验证码错误" in response.text:
                print(f"验证码错误: {captcha_code}，重试")
                time.sleep(random.uniform(0.5, 2))
                continue
            else:
                print("其他错误")
                return False
        print("重试次数用完")
        return False

if __name__ == "__main__":
    spider = CaptchaSpider()
    spider.login("username", "password")
```

## 注意事项

1. **OCR识别率** — 简单验证码ddddocr识别率90%+，复杂的还是要打码平台
2. **打码平台收费** — 按次收费，一般1-5元/千次，量大成本不低
3. **验证码时效** — 验证码有有效期，识别后要尽快提交，过期就失效了
4. **不要硬刚** — 能不触发验证码就不触发，控制频率比识别验证码更重要
5. **滑块/点选** — 这类验证码OCR搞不定，必须用打码平台或机器学习
