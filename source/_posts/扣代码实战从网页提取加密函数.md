## 适用场景

已经通过断点找到了加密函数，但函数在一大段混淆代码里，不知道怎么提取出来单独运行。需要学习"扣代码"的技巧，把加密函数从网页中提取出来。

## 实现原理

扣代码就是把网页中需要的JS函数和它依赖的所有代码复制出来，在Node.js中单独运行。核心是找到函数的定义和它依赖的所有变量、函数，确保复制出来的代码能独立运行。

## 具体步骤

### 第一步：定位加密函数

1. 设置XHR断点，触发请求
2. 在调用栈中找到业务代码
3. 单步跟踪，找到加密函数
4. 在函数定义处打断点
5. 查看函数的完整代码

### 第二步：复制函数代码

在Sources面板中：
1. 找到函数定义的位置
2. 选中函数代码（从function开始到结束的大括号）
3. 复制
4. 粘贴到本地文件

```javascript
// 复制出来的函数
function encrypt(password, key) {
    var _0x1234 = function(a, b) {
        // 内部函数
    };
    // 加密逻辑
    return result;
}
```

### 第三步：分析依赖

函数可能依赖外部变量和函数，需要找出来：

```javascript
// 加密函数
function encrypt(password) {
    // 依赖外部变量
    var key = APP_KEY;  // 外部变量
    // 依赖外部函数
    var md5 = hex_md5(password);  // 外部函数
    // 依赖内部函数
    var result = pad(password);  // 内部函数
    
    function pad(str) {
        // 内部定义的函数
    }
    
    return result;
}
```

需要找的依赖：
1. **外部变量**：函数中使用但不在函数内定义的变量
2. **外部函数**：函数中调用但不在函数内定义的函数
3. **全局对象**：window、document、navigator等

### 第四步：查找依赖的方法

**方法1：看作用域（Scope）**
- 在函数内打断点
- 暂停时看Scope面板
- Local：局部变量
- Closure：闭包变量（外部函数的变量）
- Global：全局变量

**方法2：搜索引用**
- 选中变量名
- 右键 → Find references
- 查看所有引用位置

**方法3：报错法**
- 把函数复制到Node.js运行
- 看报错`xxx is not defined`
- 逐个补全依赖

### 第五步：补全依赖

```javascript
// 1. 补全外部变量
const APP_KEY = "your_app_key";
const APP_SECRET = "your_app_secret";

// 2. 补全外部函数
function hex_md5(str) {
    // 从网页中复制md5函数
    // 或者用crypto-js
    const crypto = require("crypto-js");
    return crypto.MD5(str).toString();
}

// 3. 加密函数
function encrypt(password) {
    var key = APP_KEY;
    var md5 = hex_md5(password);
    // ...
    return result;
}

// 导出
module.exports = { encrypt };
```

### 第六步：处理闭包

有些函数在闭包里，外部访问不到：

```javascript
// 原代码
(function() {
    function encrypt(password) {
        // 加密逻辑
    }
    // 没有导出，外部访问不到
})();
```

解决方法：
1. 在函数内打断点，用`console.log(encrypt.toString())`打印函数代码
2. 或者修改代码，把函数挂到window上
3. 用Overrides替换JS文件，添加导出代码

```javascript
// 修改后
(function() {
    function encrypt(password) {
        // 加密逻辑
    }
    window.encrypt = encrypt;  // 挂到window上
})();
```

### 第七步：处理混淆的字符串

混淆代码中的字符串可能是加密的，需要先解密：

```javascript
// 原代码
var url = _0x1234('0x1');

// 解密后
var url = "https://api.example.com";
```

方法：
1. 在Console中运行解密函数，批量解密
2. 或者把解密函数也一起扣出来
3. 用AST工具批量替换

### 第八步：测试运行

```javascript
// test.js
const { encrypt } = require("./encrypt.js");

// 用已知的输入输出测试
const input = "123456";
const expected = "已知的加密结果";
const result = encrypt(input);

console.log("输入:", input);
console.log("输出:", result);
console.log("期望:", expected);
console.log("匹配:", result === expected ? "成功" : "失败");
```

如果结果不匹配，检查：
1. 依赖是否补全
2. 环境是否一致（时间戳、随机数等）
3. 编码方式是否一致
4. 是否有浏览器特定的API

## 完整代码

```javascript
// encrypt.js - 扣出来的完整加密模块

// ========== 依赖部分 ==========
const crypto = require("crypto-js");

// 外部变量
const APP_KEY = "your_app_key";
const APP_SECRET = "your_app_secret";

// 外部函数（用crypto-js替代）
function hex_md5(str) {
    return crypto.MD5(str).toString();
}

function base64_encode(str) {
    return Buffer.from(str).toString("base64");
}

// ========== 扣出来的加密函数 ==========
function encrypt(password, timestamp) {
    // 从网页中扣出来的加密逻辑
    var key = APP_KEY;
    var secret = APP_SECRET;
    
    // 第一步：MD5
    var md5_result = hex_md5(password + timestamp);
    
    // 第二步：拼接
    var sign_str = key + md5_result + secret + timestamp;
    
    // 第三步：再次MD5
    var sign = hex_md5(sign_str);
    
    return {
        sign: sign,
        timestamp: timestamp
    };
}

function generateSign(params) {
    // 生成接口签名
    var keys = Object.keys(params).sort();
    var str = "";
    for (var i = 0; i < keys.length; i++) {
        str += keys[i] + "=" + params[keys[i]] + "&";
    }
    str += "key=" + APP_SECRET;
    return hex_md5(str).toUpperCase();
}

// ========== 导出 ==========
module.exports = {
    encrypt: encrypt,
    generateSign: generateSign
};
```

```javascript
// test.js - 测试脚本
const { encrypt, generateSign } = require("./encrypt.js");

// 测试加密
const timestamp = "1699999999";
const result = encrypt("123456", timestamp);
console.log("加密结果:", result);

// 测试签名
const params = { username: "admin", page: 1 };
const sign = generateSign(params);
console.log("签名:", sign);
```

## 注意事项

1. **依赖要找全** — 少一个依赖就会报错，用Scope面板和报错法逐个找
2. **闭包处理** — 闭包里的函数要想办法导出，或者一起扣出来
3. **环境一致** — 注意时间戳、随机数、浏览器API等环境差异
4. **测试验证** — 一定要用已知的输入输出测试，确保扣的代码正确
5. **不要硬扣** — 太复杂的代码可以用puppeteer在浏览器里运行，不用硬扣
