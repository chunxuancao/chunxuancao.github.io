## 适用场景

需要分析网站或APP的接口，但不知道该用哪个抓包工具。需要了解各抓包工具的特点，选择适合自己的。

## 实现原理

抓包工具通过设置HTTP代理，拦截客户端和服务器之间的流量，从而查看和修改请求/响应。不同的抓包工具有不同的特点和适用场景，有的适合网页，有的适合APP，有的适合自动化脚本。

## 具体步骤

### 第一步：Fiddler（Windows首选）

**特点：**
- Windows平台最经典的抓包工具
- 免费（Fiddler Classic）
- 功能强大，界面友好
- 支持HTTP/HTTPS抓包
- 支持修改请求/响应
- 支持断点调试

**优点：**
- 免费，功能全
- Windows下体验最好
- 插件丰富
- 中文资料多

**缺点：**
- 跨平台差（Mac/Linux体验不好）
- 新版Fiddler Everywhere收费
- 大流量时会卡

**适用场景：**
- Windows用户
- 网页抓包
- 接口分析
- 初学者入门

**下载：** https://www.telerik.com/fiddler/fiddler-classic

### 第二步：Charles（Mac首选）

**特点：**
- 跨平台（Windows/Mac/Linux）
- 界面简洁美观
- 移动端抓包体验好
- 支持SSL代理
- 支持弱网模拟

**优点：**
- 跨平台好
- Mac下体验最好
- 移动端抓包方便
- 弱网测试功能强

**缺点：**
- 收费（免费版每次只能用30分钟，会弹窗）
- 功能比Fiddler略少
- 中文资料相对少

**适用场景：**
- Mac用户
- 移动端APP抓包
- 弱网测试
- 跨平台开发

**下载：** https://www.charlesproxy.com/

### 第三步：mitmproxy（命令行/脚本化）

**特点：**
- 命令行工具，也有Web界面
- 基于Python，可脚本化
- 支持HTTP/HTTPS/WebSocket
- 支持用Python脚本处理流量
- 开源免费

**优点：**
- 开源免费
- 可脚本化，自动化能力强
- 跨平台
- 轻量级，性能好
- 适合集成到爬虫流程中

**缺点：**
- 命令行界面，新手不友好
- 需要一定Python基础
- 图形界面不如Fiddler/Charles直观

**适用场景：**
- 自动化抓包
- 批量处理请求
- 集成到爬虫/测试流程
- 高级用户

**安装：**
```bash
pip install mitmproxy
# 运行
mitmweb  # Web界面
mitmdump  # 命令行，可运行脚本
```

**脚本示例：**
```python
# add_header.py - 自动添加请求头
from mitmproxy import http

def request(flow: http.HTTPFlow) -> None:
    flow.request.headers["User-Agent"] = "Mozilla/5.0"
    print(f"请求: {flow.request.url}")

def response(flow: http.HTTPFlow) -> None:
    print(f"响应: {flow.response.status_code}")
```
运行：`mitmdump -s add_header.py`

### 第四步：Wireshark（底层网络分析）

**特点：**
- 最强大的网络协议分析工具
- 支持所有网络协议（TCP/UDP/HTTP/HTTPS等）
- 可以看到最底层的网络包
- 开源免费

**优点：**
- 功能最强大
- 支持所有协议
- 开源免费
- 跨平台

**缺点：**
- 学习曲线陡峭
- HTTPS内容看不到（需要SSLKEYLOGFILE）
- 界面复杂，新手难上手
- 主要用于网络层分析，不适合应用层抓包

**适用场景：**
- 底层网络问题排查
- 非HTTP协议分析
- 网络安全分析
- 高级用户

**下载：** https://www.wireshark.org/

### 第五步：Chrome开发者工具（最简单）

**特点：**
- Chrome浏览器内置
- 不需要额外安装
- Network面板可以抓包
- 支持XHR过滤、请求分析

**优点：**
- 零安装
- 简单易用
- 和浏览器无缝集成
- 适合网页分析

**缺点：**
- 只能抓浏览器的流量
- 不能抓APP
- 修改请求功能弱
- 不能抓HTTPS的加密内容（但浏览器自己能解密）

**适用场景：**
- 网页接口分析
- 初学者入门
- 简单的请求查看

### 第六步：其他工具

**1. HttpCanary（安卓抓包）**
- 安卓手机上的抓包工具
- 不需要电脑，手机直接抓
- 需要ROOT或VPN模式
- 适合移动端快速分析

**2. Stream（iOS抓包）**
- iPhone上的抓包工具
- 通过VPN模式抓包
- 适合iOS开发者

**3. Postman（接口测试）**
- 不是严格的抓包工具
- 但可以构造和测试请求
- 适合接口调试

**4. whistle（开源抓包）**
- 基于Node.js的抓包工具
- 类似Fiddler，跨平台
- 支持规则配置
- 开源免费

### 第七步：工具选择建议

| 场景 | 推荐工具 |
|------|---------|
| Windows网页抓包 | Fiddler |
| Mac网页抓包 | Charles |
| 移动端APP抓包 | Charles |
| 自动化/脚本化 | mitmproxy |
| 简单网页分析 | Chrome DevTools |
| 底层网络分析 | Wireshark |
| 安卓手机抓包 | HttpCanary |
| iPhone抓包 | Stream |

**新手推荐路径：**
1. 先用Chrome开发者工具，了解基本概念
2. 再学Fiddler（Windows）或Charles（Mac）
3. 需要自动化时学mitmproxy
4. 遇到底层问题再学Wireshark

## 完整代码

```python
# mitmproxy 爬虫辅助脚本示例
# 运行: mitmdump -s spider_helper.py

from mitmproxy import http
import json
import csv
from datetime import datetime

class SpiderHelper:
    def __init__(self):
        self.api_calls = []
        self.output_file = "api_calls.csv"
    
    def request(self, flow: http.HTTPFlow):
        # 记录所有API请求
        if "/api/" in flow.request.url:
            print(f"[{datetime.now()}] {flow.request.method} {flow.request.url}")
            print(f"  参数: {flow.request.query}")
    
    def response(self, flow: http.HTTPFlow):
        # 保存API响应
        if "/api/" in flow.request.url and flow.response:
            try:
                data = json.loads(flow.response.text)
                self.api_calls.append({
                    "url": flow.request.url,
                    "method": flow.request.method,
                    "status": flow.response.status_code,
                    "response": json.dumps(data, ensure_ascii=False)[:500]
                })
                # 保存到文件
                with open(self.output_file, "a", newline="", encoding="utf-8") as f:
                    writer = csv.DictWriter(f, fieldnames=["url", "method", "status", "response"])
                    if f.tell() == 0:
                        writer.writeheader()
                    writer.writerow(self.api_calls[-1])
            except:
                pass
    
    def done(self):
        print(f"共记录 {len(self.api_calls)} 个API请求")

addons = [SpiderHelper()]
```

## 注意事项

1. **HTTPS证书** — 抓HTTPS必须安装并信任证书，不然抓不到内容
2. **APP抓包** — 很多APP有SSL Pinning，需要ROOT/越狱或Frida绕过
3. **证书安全** — 抓包工具的根证书要保管好，用完可以删除
4. **系统代理** — 抓包工具会修改系统代理，用完记得恢复，不然上不了网
5. **法律风险** — 不要抓别人的敏感数据，注意合规
