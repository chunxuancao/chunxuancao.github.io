## 适用场景

接口请求里有sign、signature、_sign等参数，每次请求都不一样，直接复制请求会失败。需要逆向分析签名算法，自己生成sign参数。

## 实现原理

签名参数是网站为了防止接口被滥用，对请求参数进行加密/哈希计算得到的一串字符串。服务器用同样的算法计算，对比是否一致。常见的签名算法有MD5、SHA、HMAC、AES等。破解需要找到生成签名的JS代码，理解算法，然后用Python复现。

## 具体步骤

### 第一步：识别签名参数

常见签名字段名：
- `sign`、`signature`、`_sign`
- `token`、`_token`、`access_token`（有些是签名）
- `timestamp` + `sign`（带时间戳）
- `nonce` + `sign`（带随机数）
- `app_key` + `app_secret` + `sign`

特征：
1. 参数值是一串十六进制字符（MD5是32位，SHA1是40位）
2. 每次请求都不一样
3. 同样的参数，sign相同（说明是参数的哈希）
4. 带timestamp，时间戳过期失效

### 第三步：分析签名算法

常见的签名模式：

**模式1：参数排序+MD5**
```javascript
// JS代码
function generateSign(params) {
    var keys = Object.keys(params).sort();
    var str = "";
    for (var i = 0; i < keys.length; i++) {
        str += keys[i] + "=" + params[keys[i]] + "&";
    }
    str += "secret=abc123";
    return md5(str);
}
```

**模式2：时间戳+密钥+MD5**
```javascript
function generateSign() {
    var timestamp = Date.now();
    var sign = md5(timestamp + "secret_key");
    return {timestamp: timestamp, sign: sign};
}
```

**模式3：HMAC-SHA256**
```javascript
function generateSign(params, secret) {
    var str = JSON.stringify(params);
    return CryptoJS.HmacSHA256(str, secret).toString();
}
```

### 第五步：Python复现签名

```python
import hashlib
import time
import json

def generate_sign_md5(params, secret="abc123"):
    """MD5签名：参数排序+拼接+密钥"""
    # 参数排序
    sorted_params = sorted(params.items())
    # 拼接字符串
    str_list = [f"{k}={v}" for k, v in sorted_params]
    sign_str = "&".join(str_list) + f"&secret={secret}"
    # MD5加密
    sign = hashlib.md5(sign_str.encode()).hexdigest()
    return sign

def generate_sign_timestamp(secret="abc123"):
    """时间戳+MD5签名"""
    timestamp = str(int(time.time() * 1000))
    sign = hashlib.md5((timestamp + secret).encode()).hexdigest()
    return timestamp, sign

def generate_sign_hmac(params, secret="abc123"):
    """HMAC-SHA256签名"""
    import hmac
    str_data = json.dumps(params, separators=(',', ':'))
    sign = hmac.new(
        secret.encode(), 
        str_data.encode(), 
        hashlib.sha256
    ).hexdigest()
    return sign
```

## 完整代码

```python
import requests
import hashlib
import time
import json

class SignSpider:
    def __init__(self):
        self.base_url = "https://api.example.com"
        self.app_key = "your_app_key"
        self.app_secret = "your_app_secret"
        self.session = requests.Session()
    
    def generate_sign(self, params):
        """生成签名：参数排序 + app_secret + MD5"""
        # 添加公共参数
        params["app_key"] = self.app_key
        params["timestamp"] = str(int(time.time()))
        params["nonce"] = hashlib.md5(str(time.time()).encode()).hexdigest()[:8]
        
        # 参数排序
        sorted_items = sorted(params.items())
        # 拼接
        sign_str = "&".join([f"{k}={v}" for k, v in sorted_items])
        sign_str += self.app_secret
        
        # MD5签名
        sign = hashlib.md5(sign_str.encode()).hexdigest()
        params["sign"] = sign
        return params
    
    def request(self, endpoint, data=None):
        """带签名的请求"""
        url = f"{self.base_url}{endpoint}"
        params = data or {}
        signed_params = self.generate_sign(params)
        
        response = self.session.post(url, json=signed_params)
        return response.json()

if __name__ == "__main__":
    spider = SignSpider()
    result = spider.request("/api/data", {"page": 1, "size": 20})
    print(result)
```

## 注意事项

1. **密钥安全** — app_secret一般硬编码在JS里，要仔细找，可能被混淆
2. **参数顺序** — 签名对参数顺序很敏感，一定要和JS里的排序方式一致
3. **编码方式** — 注意URL编码、JSON序列化的格式（空格、逗号等）
4. **时间戳** — 服务器会校验时间戳，误差不能太大（一般5分钟内）
5. **算法确认** — 用已知的输入输出测试Python复现是否正确
