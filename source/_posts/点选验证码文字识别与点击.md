## 适用场景

验证码要求按顺序点击图片中的文字或图标，比如12306的图片点选、腾讯防水墙的文字点选。需要识别文字位置，然后模拟点击。

## 实现原理

点选验证码要求用户按提示顺序点击图片中的特定文字或图标。爬虫需要：1）OCR识别图片中的文字和位置；2）根据提示文字找到对应的坐标；3）模拟人类的点击轨迹和间隔。

## 具体步骤

### 第一步：点选验证码类型

1. **文字点选** — 提示"请依次点击：猫、狗、鱼"，图片中有多个文字
2. **图片点选** — 12306类型，提示"点击所有符合要求的图片"
3. **图标点选** — 点击特定的图标或符号
4. **语序点选** — 按语义顺序点击文字

### 第二步：获取验证码图片

### 第三步：OCR识别文字位置

```python
import ddddocr
from PIL import Image

def recognize_text_positions(image_path):
    """识别图片中所有文字的位置"""
    det = ddddocr.DdddOcr(det=True)  # 检测模式
    
    with open(image_path, "rb") as f:
        image_bytes = f.read()
    
    # 检测文字位置，返回每个文字的 bounding box
    positions = det.detection(image_bytes)
    
    # positions格式：[[x1, y1, x2, y2], ...]
    return positions

def recognize_text(image_path, bbox):
    """识别指定区域的文字"""
    ocr = ddddocr.DdddOcr()
    image = Image.open(image_path)
    
    # 裁剪文字区域
    x1, y1, x2, y2 = bbox
    text_image = image.crop((x1, y1, x2, y2))
    
    # 识别文字
    text = ocr.classification(text_image.tobytes())
    return text
```

### 第四步：匹配提示文字和坐标

```python
def match_positions(image_path, tip_text):
    """根据提示文字，找到对应的点击坐标"""
    # 提取提示中的目标文字
    target_words = extract_target_words(tip_text)
    # 如 ["春天", "夏天", "秋天"]
    
    # 识别图片中所有文字位置
    positions = recognize_text_positions(image_path)
    
    # 识别每个位置的文字，建立映射
    word_positions = {}
    for bbox in positions:
        word = recognize_text(image_path, bbox)
        # 计算中心点坐标
        center_x = (bbox[0] + bbox[2]) // 2
        center_y = (bbox[1] + bbox[3]) // 2
        word_positions[word] = (center_x, center_y)
    
    # 按提示顺序返回坐标
    click_positions = []
    for word in target_words:
        if word in word_positions:
            click_positions.append(word_positions[word])
    
    return click_positions
```

### 第七步：打码平台方案

复杂的点选验证码用打码平台：

```python
import requests
import base64

class CaptchaPlatform:
    def __init__(self, username, password):
        self.username = username
        self.password = password
    
    def click_captcha(self, image_path, tip_text):
        """点选验证码打码"""
        with open(image_path, "rb") as f:
            image_base64 = base64.b64encode(f.read()).decode()
        
        data = {
            "user": self.username,
            "pass": self.password,
            "codetype": "9001",  # 点选验证码类型
            "file_base64": image_base64,
            "text": tip_text  # 提示文字
        }
        
        response = requests.post("https://api.chaojiying.com/Upload/Processing.php", data=data)
        result = response.json()
        
        if result["err_no"] == 0:
            # 返回坐标，格式："x1,y1|x2,y2|x3,y3"
            positions = []
            for pos in result["pic_str"].split("|"):
                x, y = pos.split(",")
                positions.append((int(x), int(y)))
            return positions
        return None
```

## 完整代码

```python
import ddddocr
import random
import time
from PIL import Image
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.common.action_chains import ActionChains

class ClickCaptcha:
    def __init__(self, driver):
        self.driver = driver
        self.det = ddddocr.DdddOcr(det=True)
        self.ocr = ddddocr.DdddOcr()
    
    def recognize_all_words(self, image_path):
        """识别图片中所有文字和位置"""
        with open(image_path, "rb") as f:
            image_bytes = f.read()
        
        # 检测文字位置
        bboxes = self.det.detection(image_bytes)
        
        # 识别每个文字
        image = Image.open(image_path)
        word_map = {}
        
        for bbox in bboxes:
            x1, y1, x2, y2 = bbox
            text_img = image.crop((x1, y1, x2, y2))
            word = self.ocr.classification(text_img.tobytes())
            center_x = (x1 + x2) // 2
            center_y = (y1 + y2) // 2
            word_map[word] = (center_x, center_y)
        
        return word_map
    
    def solve(self, image_path, tip_text):
        """解决点选验证码"""
        # 提取目标文字
        target_words = self._extract_targets(tip_text)
        
        # 识别所有文字
        word_map = self.recognize_all_words(image_path)
        
        # 按顺序匹配
        positions = []
        for word in target_words:
            if word in word_map:
                positions.append(word_map[word])
            else:
                # 模糊匹配
                for key in word_map:
                    if word in key or key in word:
                        positions.append(word_map[key])
                        break
        
        return positions
    
    def _extract_targets(self, tip_text):
        """从提示文字中提取目标"""
        # 提示如"请依次点击：春天、夏天、秋天"
        import re
        match = re.search(r"[：:](.+)", tip_text)
        if match:
            words = re.split(r"[、,，]", match.group(1))
            return [w.strip() for w in words if w.strip()]
        return []
    
    def click(self, element_selector, positions):
        """模拟点击"""
        element = self.driver.find_element(By.CSS_SELECTOR, element_selector)
        location = element.location
        
        for x, y in positions:
            # 移动到位置
            ActionChains(self.driver).move_to_element_with_offset(
                element, x, y
            ).perform()
            time.sleep(random.uniform(0.3, 0.8))
            
            # 点击
            ActionChains(self.driver).click().perform()
            time.sleep(random.uniform(0.8, 1.5))

if __name__ == "__main__":
    driver = webdriver.Chrome()
    driver.get("https://example.com/login")
    
    captcha = ClickCaptcha(driver)
    positions = captcha.solve("captcha.png", "请依次点击：春天、夏天、秋天")
    print(f"点击坐标: {positions}")
    captcha.click(".captcha-image", positions)
```

## 注意事项

1. **识别率** — ddddocr对点选验证码的文字检测可能不准，复杂的要用打码平台
2. **坐标缩放** — 图片显示尺寸和实际尺寸可能不同，要计算缩放比例
3. **点击顺序** — 一定要按提示的顺序点击，顺序错了验证失败
4. **点击间隔** — 不要点太快，模拟人类思考时间，间隔0.5-1.5秒
5. **12306类型** — 图片点选需要分类模型，比文字点选更难
