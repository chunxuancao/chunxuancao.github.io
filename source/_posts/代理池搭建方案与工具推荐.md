## 适用场景

爬取量大了被封IP，需要用代理池轮换IP。需要了解代理的类型、搭建方案和工具，选择适合自己的代理方案。

## 实现原理

代理池维护一批可用的代理IP，每次请求随机或轮询使用不同的IP，避免同一IP请求过多被封禁。代理池需要包含：代理获取、代理验证、代理存储、代理调度四个模块。

## 具体步骤

### 第一步：代理类型

**按匿名度分：**

| 类型 | 匿名度 | 说明 | 价格 |
|------|--------|------|------|
| 透明代理 | 最低 | 会暴露真实IP | 免费 |
| 匿名代理 | 中等 | 隐藏真实IP，但标识是代理 | 便宜 |
| 高匿代理 | 最高 | 完全隐藏真实IP | 中等 |
| 住宅代理 | 最高 | 真实家庭宽带IP | 贵 |

**按来源分：**
- **免费代理** — 从免费代理网站爬取，质量差，可用率低
- **付费代理** — 购买代理服务商的API，质量有保障
- **自建代理** — 自己买服务器搭建，成本高但稳定
- **ADSL代理** — 拨号服务器，自动换IP，适合高并发

### 第五步：自己写简单代理池

```python
import requests
import random
import time
from threading import Lock

class SimpleProxyPool:
    def __init__(self, api_url=None):
        self.api_url = api_url  # 付费代理API
        self.proxies = []
        self.lock = Lock()
        self.last_fetch = 0
    
    def fetch_proxies(self):
        """从API获取代理"""
        if not self.api_url:
            return []
        try:
            response = requests.get(self.api_url, timeout=10)
            data = response.json()
            new_proxies = [f"{item['ip']}:{item['port']}" for item in data.get('data', [])]
            with self.lock:
                self.proxies.extend(new_proxies)
            return new_proxies
        except Exception as e:
            print(f"获取代理失败: {e}")
            return []
    
    def validate_proxy(self, proxy):
        """验证代理是否可用"""
        try:
            response = requests.get(
                "https://httpbin.org/ip",
                proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                timeout=5
            )
            return response.status_code == 200
        except:
            return False
    
    def get_proxy(self):
        """获取一个可用代理"""
        with self.lock:
            if not self.proxies or time.time() - self.last_fetch > 60:
                self.fetch_proxies()
                self.last_fetch = time.time()
            if not self.proxies:
                return None
            return random.choice(self.proxies)
    
    def remove_proxy(self, proxy):
        """移除失效代理"""
        with self.lock:
            if proxy in self.proxies:
                self.proxies.remove(proxy)

# 使用
pool = SimpleProxyPool(api_url="your_proxy_api")
for i in range(10):
    proxy = pool.get_proxy()
    try:
        response = requests.get(
            "https://example.com",
            proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
            timeout=10
        )
        print(f"请求成功: {response.status_code}")
    except Exception as e:
        print(f"代理失效: {proxy}")
        pool.remove_proxy(proxy)
```

```python
index = 0
def get_proxy():
    global index
    proxy = proxy_list[index % len(proxy_list)]
    index += 1
    return proxy
```

**3. 按请求数轮换**
```python
request_count = 0
current_proxy = None
def get_proxy():
    global request_count, current_proxy
    if request_count % 10 == 0 or not current_proxy:
        current_proxy = random.choice(proxy_list)
    request_count += 1
    return current_proxy
```

**4. 失败自动切换**
```python
def fetch_with_retry(url, max_retries=3):
    for i in range(max_retries):
        proxy = pool.get_proxy()
        try:
            response = requests.get(url, proxies={"http": proxy, "https": proxy}, timeout=10)
            if response.status_code == 200:
                return response
        except:
            pool.remove_proxy(proxy)
    return None
```

        if proxy and proxy in self.proxies:
            self.proxies.remove(proxy)
        return request  # 重试

## 完整代码

```python
# proxy_pool.py - 完整的代理池实现
import requests
import random
import time
import threading
from queue import Queue

class ProxyPool:
    def __init__(self, api_url=None, min_proxies=10):
        self.api_url = api_url
        self.min_proxies = min_proxies
        self.proxies = Queue()
        self.lock = threading.Lock()
        self.running = True
        
        # 启动后台线程定期补充代理
        self.thread = threading.Thread(target=self._auto_fetch, daemon=True)
        self.thread.start()
    
    def _auto_fetch(self):
        """自动补充代理"""
        while self.running:
            if self.proxies.qsize() < self.min_proxies:
                self.fetch_proxies()
            time.sleep(30)
    
    def fetch_proxies(self):
        """从API获取代理"""
        if not self.api_url:
            return
        try:
            response = requests.get(self.api_url, timeout=10)
            data = response.json()
            for item in data.get('data', []):
                proxy = f"{item['ip']}:{item['port']}"
                if self._validate(proxy):
                    self.proxies.put(proxy)
            print(f"代理池当前数量: {self.proxies.qsize()}")
        except Exception as e:
            print(f"获取代理失败: {e}")
    
    def _validate(self, proxy):
        """验证代理"""
        try:
            response = requests.get(
                "https://httpbin.org/ip",
                proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                timeout=5
            )
            return response.status_code == 200
        except:
            return False
    
    def get_proxy(self):
        """获取代理"""
        try:
            return self.proxies.get(timeout=5)
        except:
            return None
    
    def return_proxy(self, proxy):
        """归还代理（可用的）"""
        if proxy:
            self.proxies.put(proxy)
    
    def close(self):
        self.running = False

# 使用示例
if __name__ == "__main__":
    pool = ProxyPool(api_url="your_proxy_api")
    time.sleep(5)  # 等待获取代理
    
    for i in range(20):
        proxy = pool.get_proxy()
        if not proxy:
            print("没有可用代理")
            time.sleep(5)
            continue
        
        try:
            response = requests.get(
                "https://httpbin.org/ip",
                proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                timeout=10
            )
            print(f"第{i}次，IP: {response.json()['origin']}")
            pool.return_proxy(proxy)  # 可用的归还
        except Exception as e:
            print(f"代理失效: {proxy}, {e}")
            # 失效的不归还
```

## 注意事项

1. **免费代理慎用** — 免费代理可能窃取数据，不要用来登录或传敏感信息
2. **代理质量** — 住宅代理 > 高匿 > 普通 > 透明，强反爬网站用住宅代理
3. **并发控制** — 代理也有并发限制，不要同时上百个请求用同一个代理
4. **成本控制** — 代理按流量或次数收费，大规模爬取成本不低
5. **法律风险** — 用代理爬取要注意合规，不要爬敏感数据
