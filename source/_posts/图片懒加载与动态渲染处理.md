## 适用场景

用requests拿到的HTML里图片URL是空的或者是占位图，或者数据根本不在HTML里。这是因为页面用了JS动态渲染和懒加载技术。

## 实现原理

现代网站为了性能优化，会用懒加载技术：图片初始不加载，滚动到可视区域时才把`data-src`属性的值赋给`src`。数据也可能通过JS异步请求API加载，初始HTML里只有空容器。

## 具体步骤

### 第一步：识别懒加载

懒加载图片的特征：
```html
<!-- 正常图片 -->
<img src="https://example.com/photo.jpg">

<!-- 懒加载图片 -->
<img data-src="https://example.com/photo.jpg" src="placeholder.jpg">
<img data-original="https://example.com/photo.jpg" src="">
<img data-lazy-src="https://example.com/photo.jpg">
```

常见的懒加载属性：
- `data-src`
- `data-original`
- `data-lazy-src`
- `data-url`
- `data-image`

### 第二步：提取懒加载图片

```python
from bs4 import BeautifulSoup

def extract_images(html):
    """提取所有图片，包括懒加载的"""
    soup = BeautifulSoup(html, "lxml")
    images = []
    
    for img in soup.find_all("img"):
        # 优先取真实URL
        url = (img.get("data-src") or 
               img.get("data-original") or 
               img.get("data-lazy-src") or 
               img.get("data-url") or 
               img.get("src"))
        
        if url and url != "placeholder.jpg":
            images.append(url)
    
    return images
```

### 第三步：识别JS动态渲染

特征：
1. requests拿到的HTML里没有数据，只有空的div容器
2. 浏览器里能看到数据，F12查看源码也没有
3. 页面有"加载中..."提示
4. URL带`#`或者用了前端路由（React/Vue）

### 第四步：找数据接口（推荐）

动态渲染的页面，数据一般是通过API加载的，直接找API比用Selenium快得多：

1. F12 → Network → Fetch/XHR
2. 刷新页面，查看所有XHR请求
3. 逐个看Preview，找包含数据的接口
4. 分析接口的URL、参数、请求头
5. 用requests直接调用接口

```python
import requests

# 找到的API接口
headers = {
    "User-Agent": "Mozilla/5.0",
    "Referer": "https://example.com/list"
}
params = {
    "page": 1,
    "size": 20
}

response = requests.get(
    "https://api.example.com/v1/articles",
    headers=headers,
    params=params
)
data = response.json()
# 直接拿到JSON数据，比解析HTML快多了
```

### 第五步：用Selenium/Playwright渲染

找不到接口或者接口有签名加密时，用浏览器渲染：

```python
from playwright.sync_api import sync_playwright

def render_page(url):
    """用Playwright渲染JS页面"""
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()
        page.goto(url)
        
        # 等待内容加载
        page.wait_for_selector(".content", timeout=10000)
        
        # 滚动到底部，触发懒加载
        page.evaluate("window.scrollTo(0, document.body.scrollHeight)")
        page.wait_for_timeout(2000)
        
        # 获取渲染后的HTML
        html = page.content()
        browser.close()
        return html
```

### 第六步：滚动加载所有懒加载内容

```python
def scroll_to_load_all(page):
    """滚动页面加载所有懒加载内容"""
    last_height = page.evaluate("document.body.scrollHeight")
    
    while True:
        # 滚动到底部
        page.evaluate("window.scrollTo(0, document.body.scrollHeight)")
        page.wait_for_timeout(1000)
        
        # 计算新高度
        new_height = page.evaluate("document.body.scrollHeight")
        if new_height == last_height:
            break  # 高度不再变化，加载完成
        last_height = new_height
```

## 完整代码

```python
import requests
from bs4 import BeautifulSoup
from playwright.sync_api import sync_playwright

class LazyLoadSpider:
    def __init__(self):
        self.headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"}
    
    def try_api_first(self, url):
        """优先尝试找API接口"""
        # 需要手动分析接口，这里是示例
        api_url = "https://api.example.com/data"
        try:
            response = requests.get(api_url, headers=self.headers, timeout=10)
            return response.json()
        except:
            return None
    
    def render_with_browser(self, url):
        """用浏览器渲染"""
        with sync_playwright() as p:
            browser = p.chromium.launch(headless=True)
            page = browser.new_page()
            page.goto(url, wait_until="networkidle")
            
            # 滚动加载所有内容
            self._scroll_to_load_all(page)
            
            # 获取HTML
            html = page.content()
            browser.close()
            return html
    
    def _scroll_to_load_all(self, page):
        """滚动加载懒加载内容"""
        for _ in range(10):  # 最多滚动10次
            page.evaluate("window.scrollTo(0, document.body.scrollHeight)")
            page.wait_for_timeout(1500)
    
    def parse_images(self, html):
        """解析图片，处理懒加载"""
        soup = BeautifulSoup(html, "lxml")
        images = []
        for img in soup.find_all("img"):
            url = (img.get("data-src") or 
                   img.get("data-original") or 
                   img.get("src"))
            if url and not url.startswith("data:"):
                images.append(url)
        return images

if __name__ == "__main__":
    spider = LazyLoadSpider()
    url = "https://example.com/gallery"
    
    # 先试API
    data = spider.try_api_first(url)
    if data:
        print("通过API获取数据")
    else:
        # API不行，用浏览器渲染
        html = spider.render_with_browser(url)
        images = spider.parse_images(html)
        print(f"通过浏览器渲染，获取{len(images)}张图片")
```

## 注意事项

1. **优先找API** — 能用API就别用Selenium，速度差10倍以上
2. **滚动等待** — 懒加载需要滚动触发，滚动后要等待图片加载
3. **占位图过滤** — 要过滤掉base64占位图和loading图
4. **无限滚动** — 有些页面是无限滚动，需要不断滚动直到没有新内容
5. **浏览器检测** — Selenium/Playwright可能被检测，需要加反检测参数
